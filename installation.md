## Требования

| Параметр | Значение |
|---|---|
| Операционная система | Android |
| Способ установки | APK-файл (установка из неизвестных источников) |
| Подключение | Интернет (мобильная сеть или Wi-Fi) |
| Геолокация | Включена (для карты и поиска ближайших автомобилей) |
| Камера | Нужна для верификации (KYC) и фотоосмотра |
| Телефон | Номер, на который приходит SMS-код |

> **Примечание:** версия iOS в текущей версии продукта не поставляется. Клиент написан на Flutter, поэтому в будущем возможна поддержка iOS.

## Установка APK

1. Скачайте установочный файл приложения Dachy на устройство.
2. Откройте **Настройки → Безопасность** (название раздела зависит от производителя) и включите разрешение **«Установка из неизвестных источников»** для браузера или файлового менеджера, из которого запускаете APK.
3. Откройте скачанный APK-файл и подтвердите установку.
4. Дождитесь завершения. На рабочем столе появится иконка Dachy.

> **Важно:** устанавливайте APK только из источника, которому доверяете (от владельца сервиса).

## Разрешения

При первом запуске приложение запросит доступ к трём функциям. Без них часть возможностей работать не будет.

| Разрешение | Зачем нужно |
|---|---|
| Геолокация | Показывает ваше положение на карте и ближайшие автомобили |
| Камера | Верификация документов (KYC) и фотоосмотр автомобиля до и после поездки |
| Хранилище (галерея) | Прикрепление готовых снимков к осмотру или сообщению в поддержку |

Если вы отклонили разрешение, его можно включить позже в системных настройках: **Настройки → Приложения → Dachy → Разрешения**.

## Первый вход

1. Откройте приложение — появится экран **«Вход в каршеринг»**.
2. Введите номер телефона в международном формате, например `+79001234567`.
3. Нажмите **«Получить код»** и введите код из SMS.
4. После подтверждения откроется главный экран с картой.

![Экран входа в каршеринг: поле номера телефона и кнопка «Получить код»](images/screen-auth.png)

Данные авторизации (токен) сохраняются на устройстве, поэтому при следующих запусках вход выполняется автоматически, пока токен действителен.

## Ограничения

- Приложение работает только при наличии интернета: цена, время и дистанция поездки запрашиваются с сервера.
- Бронирование доступно только пользователям со статусом KYC `verified`.
- Завершить аренду можно только на парковке в разрешённой геозоне.
- Раздел «Новости» и подписка «Клуб Dachy» пока работают в тестовом режиме (заглушки).
